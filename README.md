# Инструкция по запуску Лабораторной работы №4 (Вариант 6)

Этот проект представляет собой клиентское приложение на языке Python для работы с внешним REST API. Программа отправляет HTTP-запрос GET к серверам Open Notify (данные NASA), получает динамические данные в формате JSON о текущих экипажах на космической орбите, а затем позволяет интерактивно фильтровать полученный список космонавтов по названию космического аппарата или станции прямо в консоли.

Шаг 2. Запуск программы
Открой встроенный терминал в VS Code непосредственно в папке проекта PythLabTim4var6 и выполни стандартную команду запуска:

Bash
python main.py
Сценарии для проверки (Метрики и интерактивные тесты)
После запуска программа свяжется с сервером NASA и предложит ввести название корабля для фильтрации данных. Ниже приведены три сценария для проверки всех веток работы приложения:

Тест 1. Вывод всех космонавтов без фильтрации:
При запросе фильтра (Enter spacecraft name to filter...) ничего не вводи, а просто нажми Enter.

Результат: Скрипт отобразит общую метрику (например: Current number of people in space: 12) и выведет сплошным списком абсолютно всех людей на орбите, включая их текущую станцию (ISS или Tiangong).

Тест 2. Фильтрация по конкретной космической станции:
При запросе фильтра введи ISS или Tiangong (регистр букв не важен, программа автоматически приводит его к нижнему) и нажми Enter.

Результат: Приложение пересчитает метрику под конкретный запрос (например: Current number of people on ISS: 9) и выведет имена только тех астронавтов, которые привязаны к выбранному аппарату.

Тест 3. Проверка защиты от некорректного ввода:
Введи несуществующее название корабля, например: Starship или любую случайную строку, и нажми Enter.

Результат: Логика фильтрации зафиксирует отсутствие совпадений в JSON-структуре и вежливо уведомит: No astronauts found on spacecraft matching: 'Starship'.

Возможные проблемы и их решение
❌ Ошибка: ModuleNotFoundError: No module named 'requests'

Причина: В твоем окружении Python не установлена сторонняя библиотека для отправки HTTP-запросов.

Решение: Выполни в терминале команду pip install requests, после чего перезапусти main.py.

❌ Ошибка: ModuleNotFoundError: No module named 'handlers'

Причина: Попытка запустить внутренний скрипт clientAPI.py напрямую из папки handlers.

Решение: Всегда запускай только корневой файл main.py, находясь в основной директории проекта.
